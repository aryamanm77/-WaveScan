💻 Offline / Command-Line Flash Option

Prefer command line? Flash the pre-compiled binary in one command using esptool.py:

pip install esptool esptool.py --chip esp32 write_flash 0x0 bin/WAVESCAN_merged_4MB.bin

🔧 Troubleshooting Tips

  • No COM port detected? Make sure your USB cable supports data transfer, and install the USB-to-UART driver (CP2102 or CH340).
  • Connection timeout during flashing? Press and hold the BOOT button on your ESP32 when the installer connects, then release it once flashing starts.
  • Android phone switches back to cellular data? Because the ESP32 AP does not route to the internet, tap "Stay connected to Wi-Fi" when Android prompts you.
